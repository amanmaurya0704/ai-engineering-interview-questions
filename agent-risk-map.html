Agentic AI · Threat Surface

Where the risks live
a step-by-step map of an AI agent's pipeline

Each stage of an agent's operating loop — from receiving input to taking action to remembering what happened — opens a distinct attack surface. Risks are placed at the stage where they're introduced, not necessarily where the damage shows up.

01 — Ingestion
STAGE 1

Input & External Data Sources

User prompts, retrieved web pages, documents, emails, API responses feeding the agent's context.

Prompt Injection (Direct & Indirect) Context / Instruction Confusion Agent Enumeration & Reconnaissance
02 — Reasoning
STAGE 2

Agent Core — LLM Planning & Decisions

The model interprets goals, plans steps, decides which tools to call and scores confidence/risk.

Goal Hijacking Decision & Approval Manipulation Model / Tool Output Hallucination Exploitation
03 — Memory
STAGE 3

Memory & Context Store

Short-term conversation state plus long-term / vector (RAG) stores persisted across turns or sessions.

Memory Poisoning Vector / RAG Store Poisoning Sensitive Data Exposure
04 — Action
STAGE 4

Tool Calls & Execution

The agent invokes APIs, scripts, or system commands — the point where words become real-world effects.

Tool Abuse & Privilege Escalation High-Impact Action Abuse Insecure Credential / Secret Handling Denial of Wallet (DoW) Unbounded Agentic Loops
05 — Coordination
STAGE 5

Multi-Agent Communication

Sub-agents or peer agents exchange tasks, results, and trust signals with each other.

Cascading Failures Cross-Agent Trust Exploitation Identity / Impersonation Spoofing
06 — Oversight
STAGE 6

Human-in-the-Loop / Approval Gate

Where a human is meant to review or authorize a high-impact action before it executes.

Excessive Autonomy Human-in-the-Loop Bypass (Rubber-Stamping) Overreliance / Automation Bias
07 — Output
STAGE 7

Response & Downstream Delivery

The final answer, file, or payload handed back to the user or piped into another system.

Data Exfiltration Insecure Output Handling Sensitive Data Exposure
Cross-cutting — not tied to a single stage

Supply Chain

Supply Chain Attacks

Feeds every stage: compromised third-party tools, plugins, models, or data sources the agent depends on.

Dev / Config Layer

AI Console Malicious Configuration

Malicious data reaching the developer console and altering the agent's own configuration.

Logging & Audit

Repudiation & Audit Gaps

Wraps the whole pipeline: missing or tamperable logs mean actions can't be traced back after the fact.
